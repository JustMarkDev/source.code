```bash
sx config list
sx config get agent.target
sx config set agent.target boat
sx config path
```

## Where settings live

`~/.config/sx/config.json`, or `$XDG_CONFIG_HOME/sx/config.json`. Set `SX_CONFIG_DIR` to use another folder.

## Order of precedence

1. A flag on the command
2. An environment variable, `SX_` plus the key in capitals, with `.` as `_`
3. The settings file
4. The default

`sx config list` shows where each value came from.

## All settings

| Key              | Default               | Environment         | Meaning                                              |
| ---------------- | --------------------- | ------------------- | ---------------------------------------------------- |
| `host`           | `https://source.code` | `SX_HOST`           | The server to talk to                                |
| `output`         | `auto`                | `SX_OUTPUT`         | `auto`, `json` or `text`                             |
| `agent.target`   | `t3`                  | `SX_AGENT_TARGET`   | Where `sx agent start` points: `t3`, `boat` or `e2b` |
| `agent.runtime`  | `claude`              | `SX_AGENT_RUNTIME`  | The agent runtime named in the prompt                |
| `change.base`    | `main`                | `SX_CHANGE_BASE`    | Base branch for new changes                          |
| `change.draft`   | `false`               | `SX_CHANGE_DRAFT`   | Create changes as drafts                             |
| `clone.protocol` | `ssh`                 | `SX_CLONE_PROTOCOL` | `ssh` or `https` for `repo clone`                    |

## Other environment variables

| Variable        | Meaning                                    |
| --------------- | ------------------------------------------ |
| `SX_TOKEN`      | A token for signing in                     |
| `SX_REPO`       | The repository when you are not in a clone |
| `SX_CONFIG_DIR` | Where the settings file lives              |
| `SX_DEBUG`      | Print stack traces                         |
| `NO_COLOR`      | Turn off colour                            |
