### `webhooks.create`

`POST /repos/{owner}/{repo}/webhooks`

**Create a webhook**

The URL must be https and must not point at a private, loopback or link-local address. The response is the only time the signing secret is shown. A repository can have 10.

| Safety     | `write`, not safe to repeat blindly |

| Rate limit | `write` pool, 1 unit                |

| Success    | `201`, a `webhook`                  |

### `webhooks.replay`

`POST /repos/{owner}/{repo}/webhooks/{webhook}/replay`

**Replay events the endpoint missed**

Sends every event after `after_sequence` that this webhook subscribes to, oldest first, up to `limit`. Use the `last_sequence` it returns to continue. A lost delivery is never a manual job.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `webhooks:write`                    |
| Rate limit | `write` pool, 1 unit                |
| Success    | `202`, a `replay`                   |

**Path parameters**

| Name      | Type   | Notes |
| --------- | ------ | ----- |
| `owner`   | string |       |
| `repo`    | string |       |
| `webhook` | string |       |

**Request body**

| Member           | Type                                  | Notes          |
| ---------------- | ------------------------------------- | -------------- |
| `after_sequence` | integer (min 0, max 9007199254740991) | Required.      |
| `limit`          | integer (min 1, max 1000)             | Default `100`. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`idempotency_key_reused`](/docs/api/errors#idempotency_key_reused), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`request_in_progress`](/docs/api/errors#request_in_progress), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)
