### `git.blob`

`GET /repos/{owner}/{repo}/git/blob`

**Read a file**

The contents as text, or base64 when the file is not valid UTF-8. Files over 1 MiB answer `413`; use `git.raw` for those.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a `blob`                            |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name   | Type                                       | Notes                                                 |
| ------ | ------------------------------------------ | ----------------------------------------------------- |
| `ref`  | string (up to 200 characters)              | A branch, or a commit id. Default: the default branch |
| `path` | string (up to 1000 characters, at least 1) | Required.                                             |

**Errors**

[`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large)

**Example**

```bash
curl "https://api.source.code/v1/repos/dana/gitfs/git/blob?path=README.md" \
  -H "Authorization: Bearer $SX_TOKEN"
```

```http
HTTP/1.1 200
etag: W/"gKybwHFpZbxOwRsK"
ratelimit: "read";r=1160;t=60
```

```json
{
  "object": "blob",
  "path": "README.md",
  "ref": "default",
  "size": 34,
  "encoding": "utf-8",
  "content": "# gitfs\n\nGit over object storage.\n"
}
```

### `git.commits`

`GET /repos/{owner}/{repo}/git/commits`

**The history of the default branch, newest first**

Follows a cursor through the newest 1,000 commits.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a list of `commit`                  |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name     | Type                     | Notes                                                              |
| -------- | ------------------------ | ------------------------------------------------------------------ |
| `limit`  | integer (min 1, max 200) | Default `50`. Items per page, 1 to 200. Larger values are clamped. |
| `cursor` | string                   | `next_cursor` from the previous page, exactly as returned          |

[`cursor_mismatch`](/docs/api/errors#cursor_mismatch), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found)

### `git.raw`

`GET /repos/{owner}/{repo}/git/raw`

**Download a file as it is**

The bytes, with no JSON around them. Served as an attachment with `nosniff` and a sandboxing Content-Security-Policy, so a file in a repository cannot run in the page that opens it.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a JSON document                     |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name   | Type                                       | Notes                                                 |
| ------ | ------------------------------------------ | ----------------------------------------------------- |
| `ref`  | string (up to 200 characters)              | A branch, or a commit id. Default: the default branch |
| `path` | string (up to 1000 characters, at least 1) | Required.                                             |

**Errors**

[`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found)

**Example**

```bash
curl "https://api.source.code/v1/repos/dana/gitfs/git/raw?path=README.md" \
```
