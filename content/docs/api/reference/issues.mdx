### `issues.list`

`GET /repos/{owner}/{repo}/issues`

**Issues in a repository**

Open by default, newest number first.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `issues:read`                              |
| Rate limit | `read` pool, 1 unit                        |
| Wait       | `?wait=20` with `If-None-Match`            |
| Fields     | `?fields=a,b.c`                            |
| Success    | `200`, a list of `issue`                   |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name     | Type                        | Notes                                                                                              |
| -------- | --------------------------- | -------------------------------------------------------------------------------------------------- |
| `limit`  | integer (min 1, max 200)    | Default `50`. Items per page, 1 to 200. Larger values are clamped.                                 |
| `cursor` | string                      | `next_cursor` from the previous page, exactly as returned                                          |
| `state`  | `open` or `closed` or `all` | Default `"open"`.                                                                                  |
| `label`  | string                      | A label name                                                                                       |
| `author` | string                      | Handle of the author                                                                               |
| `fields` | string                      | Comma list of fields to return, dotted for nested. `object` and `id` always stay.                  |
| `wait`   | integer (min 0, max 30)     | With If-None-Match: hold the request up to this many seconds until the ETag would change. 0 to 30. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`cursor_mismatch`](/docs/api/errors#cursor_mismatch), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
  -H "Authorization: Bearer $SX_TOKEN"
```

### `issues.create`

`POST /repos/{owner}/{repo}/issues`

**Open an issue**

Naturally idempotent: an open issue with the same title is returned instead of a second one. `Sx-Outcome` is created or unchanged.

| About      |                         |
| ---------- | ----------------------- |
| Safety     | `write`, safe to repeat |
| Needs      | a token                 |
| Scopes     | `issues:write`          |
| Rate limit | `write` pool, 1 unit    |
| Dry run    | `?dry_run=true`         |
| Success    | `201`, a `issue`        |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Request body**

| Member   | Type                                      | Notes     |
| -------- | ----------------------------------------- | --------- |
| `title`  | string (up to 300 characters, at least 1) | Required. |
| `body`   | string (up to 65536 characters)           |           |
| `labels` | array of string (up to 50 characters)     |           |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`idempotency_key_reused`](/docs/api/errors#idempotency_key_reused), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`request_in_progress`](/docs/api/errors#request_in_progress), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl -X POST "https://api.source.code/v1/repos/dana/gitfs/issues" \
  -H "Authorization: Bearer $SX_TOKEN" \
  -H "idempotency-key: c1f0e7a2-5b1d-4f3a-9a7c-2d6e8b0f4a11" \
  -H "Content-Type: application/json" \
  -d '{"title":"Crash on empty repo","labels":["bug"]}'
```

**Path parameters**

| Name     | Type                                  | Notes |
| -------- | ------------------------------------- | ----- |

| `repo`   | string                                |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |

**Request body**
