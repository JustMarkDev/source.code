### `events.list`

`GET /events`

**The event log, oldest first**

Everything that happened in repositories you can see. Pass the last `next_cursor` to continue. Events are kept for 30 days. `type` takes a comma list; `change.*` matches every change event.

| About      |                                 |
| ---------- | ------------------------------- |
| Safety     | `read`, safe to repeat          |
| Needs      | a token                         |
| Scopes     | `repo:read`                     |
| Rate limit | `read` pool, 1 unit             |
| Wait       | `?wait=20` with `If-None-Match` |
| Fields     | `?fields=a,b.c`                 |
| Success    | `200`, a list of `event`        |

**Query parameters**

| Name     | Type                     | Notes                                                                                              |
| -------- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| `limit`  | integer (min 1, max 200) | Default `50`. Items per page, 1 to 200. Larger values are clamped.                                 |
| `cursor` | string                   | `next_cursor` from the previous page, exactly as returned                                          |
| `repo`   | string                   | Only this repository, `owner/name`                                                                 |
| `type`   | string                   | Comma list of event types. `change.*` matches every change event                                   |
| `fields` | string                   | Comma list of fields to return, dotted for nested. `object` and `id` always stay.                  |
| `wait`   | integer (min 0, max 30)  | With If-None-Match: hold the request up to this many seconds until the ETag would change. 0 to 30. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`cursor_mismatch`](/docs/api/errors#cursor_mismatch), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl "https://api.source.code/v1/events?repo=dana/gitfs&type=issue.*&limit=2" \
  -H "Authorization: Bearer $SX_TOKEN"
```

### `events.stream`

`GET /events/stream`

**Events as they happen (Server-Sent Events)**

A text/event-stream. Each event carries its sequence as the SSE id, so a reconnect with Last-Event-ID continues without a gap inside the retention window. A comment line is sent every 15 seconds to keep the connection open.

| About      |                              |
| ---------- | ---------------------------- |
| Safety     | `read`, safe to repeat       |
| Needs      | a token                      |
| Scopes     | `repo:read`                  |
| Rate limit | `read` pool, 1 unit          |
| Success    | `200`, a `text/event-stream` |

**Query parameters**

| Name   | Type   | Notes                              |
| ------ | ------ | ---------------------------------- |
| `repo` | string | Only this repository, `owner/name` |
| `type` | string | Comma list of event types          |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_version`](/docs/api/errors#unsupported_version)

### `operations.get`

| Scopes     | `repo:read`                     |
| Rate limit | `read` pool, 1 unit             |

| Success    | `200`, a `operation`            |

### `sync.get`

`GET /sync`

**Keep a local copy of a repository up to date**

Call without a cursor for a snapshot of the repository, its changes and its issues. Then call with the returned cursor to get only what changed, newest state of each object. When `reset` is true the cursor was too old and `objects` is a fresh snapshot. One request replaces polling every list.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Wait       | `?wait=20` with `If-None-Match`            |
| Success    | `200`, a `sync`                            |

**Query parameters**

| Name     | Type                     | Notes                                                                                              |
| -------- | ------------------------ | -------------------------------------------------------------------------------------------------- |
| `repo`   | string (pattern)         | Required. `owner/name` or a repository id `rep_...`                                                |
| `cursor` | string                   | The `cursor` of the previous response. Omit for a snapshot.                                        |
| `limit`  | integer (min 1, max 200) | Default `100`. Objects per response, 1 to 200                                                      |
| `wait`   | integer (min 0, max 30)  | With If-None-Match: hold the request up to this many seconds until the ETag would change. 0 to 30. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`cursor_mismatch`](/docs/api/errors#cursor_mismatch), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**
