### `runs.start`

`POST /repos/{owner}/{repo}/runs`

**Start a run and get a token for it**

A run is one bounded piece of work by an agent. Starting one mints a token limited to this repository, with only the scopes asked for (never more than yours, never `tokens:manage`), that stops working when the run ends or after `ttl_minutes`. The token is in the response once. Give it to the agent and keep your own. Everything the agent does is attributed to you as an agent. At most 20 runs may be going at once.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `repo:write`, `tokens:manage`       |
| Rate limit | `write` pool, 1 unit                |
| Dry run    | `?dry_run=true`                     |
| Success    | `201`, a `run`                      |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Request body**

| Member        | Type                                                                                                                                                                                                                                                                                   | Notes                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `task`        | string (up to 500 characters, at least 1)                                                                                                                                                                                                                                              | Required. What the run is for, in a sentence                      |
| `change`      | integer (min 1, max 9007199254740991)                                                                                                                                                                                                                                                  | The change it works on                                            |
| `scopes`      | array of `repo:read` or `repo:write` or `issues:read` or `issues:comment` or `issues:write` or `pulls:read` or `pulls:comment` or `pulls:write` or `pulls:merge` or `secrets:schema` or `secrets:write` or `secrets:decrypt` or `webhooks:read` or `webhooks:write` or `tokens:manage` | Default: read, comment on issues and changes, read the env schema |
| `ttl_minutes` | integer (min 1, max 240)                                                                                                                                                                                                                                                               | Default `60`.                                                     |
