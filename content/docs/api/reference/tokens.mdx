### `authorizations.list`

`GET /authorizations`

**Applications you have authorized**

The OAuth grants on your account: which application, what it may do, when it was last used.

| About      |                                  |
| ---------- | -------------------------------- |
| Safety     | `read`, safe to repeat           |
| Needs      | a token                          |
| Scopes     | `tokens:manage`                  |
| Rate limit | `read` pool, 1 unit              |
| Success    | `200`, a list of `authorization` |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_version`](/docs/api/errors#unsupported_version)

### `tokens.create`

`POST /tokens`

**Create a token**

The response is the only time the secret is shown. A token can never have a scope its creator lacks, never outlives a year, and a token limited to repositories can only create tokens limited to the same ones.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `tokens:manage`                     |
| Rate limit | `write` pool, 1 unit                |
| Dry run    | `?dry_run=true`                     |
| Success    | `201`, a `token`                    |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Request body**

| Member            | Type                                                                                                                                                                                                                                                                                   | Notes                                                |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `name`            | string (up to 100 characters, at least 1)                                                                                                                                                                                                                                              | Required.                                            |
| `scopes`          | array of `repo:read` or `repo:write` or `issues:read` or `issues:comment` or `issues:write` or `pulls:read` or `pulls:comment` or `pulls:write` or `pulls:merge` or `secrets:schema` or `secrets:write` or `secrets:decrypt` or `webhooks:read` or `webhooks:write` or `tokens:manage` | Required.                                            |
| `expires_in_days` | `30` or `60` or `90` or `365`                                                                                                                                                                                                                                                          | Default `90`.                                        |
| `repos`           | array of string (pattern)                                                                                                                                                                                                                                                              | `owner/name`. Limits the token to these repositories |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`limit_reached`](/docs/api/errors#limit_reached), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash

  -H "Authorization: Bearer $SX_TOKEN" \

  -d '{"name":"ci","scopes":["repo:read","pulls:read"],"expires_in_days":30,"repos":["dana/gitfs"]}'
```
