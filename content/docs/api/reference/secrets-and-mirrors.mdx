### `env.values`

`GET /repos/{owner}/{repo}/env/{environment}/values`

**Read values**

### `mirrors.create`

`POST /repos/{owner}/{repo}/mirrors`

**Add a mirror**

Naturally idempotent: the same host and repository returns the existing mirror with `Sx-Outcome: unchanged`.

| About      |                         |
| ---------- | ----------------------- |
| Safety     | `write`, safe to repeat |
| Needs      | a token                 |
| Scopes     | `repo:write`            |
| Rate limit | `write` pool, 1 unit    |
| Dry run    | `?dry_run=true`         |

| Name    | Type   | Notes |

| `repo`  | string |       |
