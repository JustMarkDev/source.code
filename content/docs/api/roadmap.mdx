Everything marked **built** runs, is covered by tests and is in these docs. Everything marked **designed** is a decision, not a feature: do not build on it yet.

## Built, on sample data

| Area                                        | What works                                                                                                                                                                                                                                                                  |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Contract                                    | Objects, IDs, lists with keyset cursors, `fields`, `expand`, `ETag` and `304`, `ndjson`, one error shape, CORS, `HEAD`.                                                                                                                                                     |
| Discovery                                   | `GET /v1`, the OpenAPI document, `/errors`, `/limits`, `/auth/principal`.                                                                                                                                                                                                   |
| Sign-in                                     | [OAuth](/docs/api/oauth) (the 2.1 profile): authorization code with PKCE, device flow, refresh rotation with replay detection, dynamic registration, revocation, discovery documents, resource indicators. One token for the API and MCP.                                   |
| Tokens                                      | Create, list, revoke. Scopes that can only shrink, repository limits, always expiring, secret shown once.                                                                                                                                                                   |
| Accounts and repositories                   | List, read, create (repeat-safe), `context`, `numbers`, [rename, edit, hide and delete](/docs/api/repositories) (the old address answers `308`), id addressing, private repositories answering `404`.                                                                       |
| [Teams](/docs/api/repositories#teams)       | Groups in an organization that give people read or write access to chosen repositories, inside the organization or not.                                                                                                                                                     |
| [Git data](/docs/api/repositories#git-data) | Directories, files (as JSON or raw bytes), history, one commit and its diff. Immutable by commit id.                                                                                                                                                                        |
| [Runs](/docs/api/runs)                      | A bounded task for an agent with a short-lived token limited to one repository and a few scopes, progress notes, outcome, cancel. Everything it does is recorded as an agent.                                                                                               |
| Changes                                     | List, read, create (repeat-safe), edit with `If-Match`, patch sets, comparing patch sets, reviews, findings, checks, policy and simulation, land, abandon, restore, mark ready, landing a stack as an operation, evidence.                                                  |
| Issues                                      | List, read, open (repeat-safe), edit, close.                                                                                                                                                                                                                                |
| [Search](/docs/api/search)                  | Repositories, changes and issues, prefix and phrase, qualifiers, no result cap, visibility applied.                                                                                                                                                                         |
| [Uploads](/docs/api/uploads)                | Signed one-time addresses, content checked against type, evidence on changes, sandboxed serving.                                                                                                                                                                            |
| [Webhooks](/docs/api/webhooks)              | Signed (Standard Webhooks), retried for about 28 hours, replay of any range, redelivery, secret rotation, SSRF protection, auto-disable.                                                                                                                                    |
| Mirrors, secrets                            | Mirrors list, add, sync, remove. Environment names and kinds, ciphertext-only writes, expiring grants for agents, audited reads.                                                                                                                                            |
| Events                                      | The log, the stream with `Last-Event-ID`, `sync`, `wait`, operations.                                                                                                                                                                                                       |
| Writes                                      | `Idempotency-Key`, `If-Match`, `expected_tree`, `dry_run`, batch.                                                                                                                                                                                                           |
| Limits                                      | Pools, headers, `429`, leased shared counters (in memory, or on Convex across nodes), concurrency guard, free `304`.                                                                                                                                                        |
| Clients                                     | The `sx` CLI and the MCP server call this API with the caller's token and are limited by its scopes. `sx auth login` uses the device flow. A generated, dependency-free [TypeScript client](/docs/api/sdk) with retries, `ETag` caching, repeat-safe writes and pagination. |
| Format                                      | `Accept: text/markdown` on a change, an issue and the context ([agents](/docs/api/agents#ask-for-text)).                                                                                                                                                                    |
| Stability                                   | OpenAPI snapshot with a build check that fails on non-additive changes.                                                                                                                                                                                                     |
| Docs                                        | The [reference](/docs/api/reference/changes) and the error list are generated from the code and fail a test when they drift.                                                                                                                                                |

## Designed, not built

| Area                      | What is missing                                                                                                                                                                                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Storage                   | The domain (accounts, repositories, changes, issues, teams, runs, webhooks, uploads, mirrors) is in memory. The hosted version implements the same surface on Convex, and reads git data from code.storage instead of the fake store. Only rate limits and idempotency keys are on Convex today.                    |
| Shared state, the rest    | Rate limits and idempotency keys are built on Convex and used when `CONVEX_URL` and `API_STORE_SECRET` are set. Still in memory: the event log (and the waiters on it), tokens, OAuth state and the search index. Until they are shared, run one API node, or accept that events, tokens and sign-ins are per node. |
| Real sign-in              | The consent page offers sample accounts. The app's own sign-in is a stand-in until Better Auth is wired in, and the OAuth server takes sessions through one interface (`SessionProvider`), so a real login is that one adapter plus a settings page for tokens and authorizations.                                  |
| Git data, more            | Branches and tags, compare, blame, archive, history of a path, and history beyond the newest 1,000 commits.                                                                                                                                                                                                         |
| Repositories and accounts | Transfer. Managing organization members. Labels, releases. Notifications, audit log, usage.                                                                                                                                                                                                                         |
| Review extras             | Line comments and threads, the browser edit draft, accepting a suggestion, sending a finding to an agent.                                                                                                                                                                                                           |
| Imports                   | Importing from other hosts. Mirrors that carry issues and changes.                                                                                                                                                                                                                                                  |
| Agents, more              | Installing and configuring bots, automations, run logs.                                                                                                                                                                                                                                                             |
| Webhooks, more            | Account-level webhooks; a webhook for several repositories.                                                                                                                                                                                                                                                         |
| Batch                     | An all-or-nothing batch within one repository.                                                                                                                                                                                                                                                                      |
| Versions                  | Pinning a token to the version current when it was created. `Deprecation` and `Sunset` headers when something is deprecated.                                                                                                                                                                                        |
| Clients, more             | Client libraries for other languages.                                                                                                                                                                                                                                                                               |
| Operations                | Latency published on the status page. A CDN in front of public reads.                                                                                                                                                                                                                                               |
