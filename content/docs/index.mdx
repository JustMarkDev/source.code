source.code hosts your repositories, reviews changes, and runs the checks you choose. It is built for people who work with agents as much as with other people.

  matters.

## How the pieces fit

| You want to                                     | Where it lives                                             |
| ----------------------------------------------- | ---------------------------------------------------------- |
| Find projects and people                        | **Discover**                                               |
| See what needs you today                        | **Home**                                                   |
| Connect a reviewer, runner or agent environment | **Settings, Integrations**, then turn it on per repository |
| Keep a copy on another host                     | **Repository settings, Mirrors and sync**                  |
| Commit environment variables safely             | **Repository settings, Secrets**                           |
| Decide what can land                            | **Repository settings, Policies**                          |

## Principles

- **Everything lives here.** Commits, issues, changes with their reviews, and releases are stored on source.code. Other hosts are copies.
- **One obvious next step.** Each screen has one primary action.
- **No surprises for agents.** They get the same rules as people, and never see secret values unless you grant it for a limited time.
