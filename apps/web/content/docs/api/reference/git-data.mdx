### `git.blob`

`GET /repos/{owner}/{repo}/git/blob`

**Read a file**

The contents as text, or base64 when the file is not valid UTF-8. Files over 1 MiB answer `413`; use `git.raw` for those.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a `blob`                            |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name   | Type                                       | Notes                                                 |
| ------ | ------------------------------------------ | ----------------------------------------------------- |
| `ref`  | string (up to 200 characters)              | A branch, or a commit id. Default: the default branch |
| `path` | string (up to 1000 characters, at least 1) | Required.                                             |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl "https://api.source.code/v1/repos/dana/gitfs/git/blob?path=README.md" \
  -H "Authorization: Bearer $SX_TOKEN"
```

```http
HTTP/1.1 200
etag: W/"gKybwHFpZbxOwRsK"
ratelimit: "read";r=1133;t=60
```

```json
{
  "object": "blob",
  "path": "README.md",
  "ref": "default",
  "size": 34,
  "encoding": "utf-8",
  "content": "# gitfs\n\nGit over object storage.\n"
}
```

### `git.commits`

`GET /repos/{owner}/{repo}/git/commits`

| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a list of `commit`                  |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |

**Query parameters**

| Name     | Type                     | Notes                                                              |
| -------- | ------------------------ | ------------------------------------------------------------------ |
| `limit`  | integer (min 1, max 200) | Default `50`. Items per page, 1 to 200. Larger values are clamped. |

### `git.tree`

`GET /repos/{owner}/{repo}/git/tree`

**List a directory**

The files and directories directly under `path`, directories first. With `recursive=true`, every file under `path` at any depth, by path, and no directories. Up to 2000 entries.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `read` pool, 1 unit                        |
| Success    | `200`, a `tree`                            |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name          | Type                           | Notes                                                                                  |
| ------------- | ------------------------------ | -------------------------------------------------------------------------------------- |
| `ref`         | string (up to 200 characters)  | A branch, or a commit id. Default: the default branch                                  |
| `path`        | string (up to 1000 characters) | Default `""`. A directory, without a leading or trailing slash. Default: the root      |
| `last_commit` | `true` or `false`              | Default `"false"`. Name the newest commit that touched each entry, from the newest 200 |
| `recursive`   | `true` or `false`              | Default `"false"`. List every file under the directory, not only its direct children   |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl "https://api.source.code/v1/repos/dana/gitfs/git/tree" \
```
