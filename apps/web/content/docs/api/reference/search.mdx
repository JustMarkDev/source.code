### `search.query`

`GET /search`

**Search repositories, changes and issues**

Words must all match; the last is a prefix. "Quoted phrases" match exactly. Qualifiers narrow the result: `type:change` `repo:dana/gitfs` `state:open` `author:ines` `label:bug`. Results are one ordered list with no cap: title matches first, then newest. Only repositories you can read are searched.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `search` pool, 1 unit                      |
| Fields     | `?fields=a,b.c`                            |
| Success    | `200`, a list of `search_result`           |

**Query parameters**

| Name     | Type                                      | Notes                                                                             |
| -------- | ----------------------------------------- | --------------------------------------------------------------------------------- |
| `limit`  | integer (min 1, max 200)                  | Default `50`. Items per page, 1 to 200. Larger values are clamped.                |
| `cursor` | string                                    | `next_cursor` from the previous page, exactly as returned                         |
| `q`      | string (up to 256 characters, at least 1) | Required. The query                                                               |
| `fields` | string                                    | Comma list of fields to return, dotted for nested. `object` and `id` always stay. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`cursor_mismatch`](/docs/api/errors#cursor_mismatch), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl "https://api.source.code/v1/search?q=negative+cache&limit=2" \
  -H "Authorization: Bearer $SX_TOKEN"
```
