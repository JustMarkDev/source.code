### `repos.delete`

`DELETE /repos/{owner}/{repo}`

**Delete a repository**

Permanent. Owners of the account and admins of the organization only. You must repeat the full name as `?confirm=owner/name`, so a mistyped path cannot delete the wrong thing. Its changes, issues, webhooks, mirrors and variables go with it; events already written stay in the log.

| About      |                                           |
| ---------- | ----------------------------------------- |
| Safety     | `destructive`, not safe to repeat blindly |
| Needs      | a token                                   |
| Scopes     | `repo:write`                              |
| Rate limit | `write` pool, 1 unit                      |
| Dry run    | `?dry_run=true`                           |
| Success    | `204`, no body                            |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |

| `confirm` | string  | `owner/name`, to confirm                                                                                |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Errors**
