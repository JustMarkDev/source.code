### `uploads.create`

`POST /uploads`

**Announce a file you are about to upload**

Say what the file is. The response has an `upload_url`: PUT the bytes there with the same Content-Type, no token needed. The address works once, for exactly this type and size, for an hour. The first bytes of images and video are checked against the type.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `repo:write`                        |
| Rate limit | `write` pool, 1 unit                |
| Dry run    | `?dry_run=true`                     |
| Success    | `201`, a `upload`                   |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Request body**

| Member         | Type                                                                                                                                                                                                                    | Notes                                                                                                                                       |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `filename`     | string (up to 200 characters, at least 1)                                                                                                                                                                               | Required.                                                                                                                                   |
| `content_type` | `image/png` or `image/jpeg` or `image/gif` or `image/webp` or `video/mp4` or `video/webm` or `application/json` or `text/plain` or `text/html` or `application/octet-stream` or `application/zip` or `application/gzip` | Required.                                                                                                                                   |

### `uploads.content`

`GET /uploads/{id}/content`

**Read the file**

You can read your own uploads with a token that has `repo:read`; without it the read answers `403 insufficient_scope`. Once a file is attached to a change, anyone who can read that repository can read it. Served with `nosniff` and a sandboxing policy; only images and video display inline. The ETag is the SHA-256, and the content never changes.
