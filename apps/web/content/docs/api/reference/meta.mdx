### `api.batch`

`POST /batch`

**Several requests in one**

Up to 25 requests. They run in parallel, each is authorised, rate limited and metered as if it had been sent alone, and each answer carries its own status. Batches do not nest. Use it to read a change, its policy and its checks in one round trip.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | none                                |
| Rate limit | `read` pool, 1 unit                 |
| Success    | `200`, a `batch`                    |

**Request body**

| Member     | Type            | Notes     |
| ---------- | --------------- | --------- |
| `requests` | array of object | Required. |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`invalid_request`](/docs/api/errors#invalid_request), [`payload_too_large`](/docs/api/errors#payload_too_large), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**

```bash
curl -X POST "https://api.source.code/v1/batch" \
  -H "Authorization: Bearer $SX_TOKEN" \
```

### `status.get`

`GET /status`

**How the service is doing**

Each area as this server measured its own answers: state, uptime over 90 days by day, and median and 95th-percentile time in the last hour. Mirror sync and pipelines come from their own state.
