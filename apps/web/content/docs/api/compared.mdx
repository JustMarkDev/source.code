We read the API documentation of GitHub, GitLab, Forgejo and Gitea, Bitbucket Cloud and git.cafe on 6 and 7 November 2026, and designed this API against what they do well and what they leave to the client. This is a claim about other people's products, so every row says what we read, links the page, and says what we could **not** confirm. Products change; check the link.

## What this API does about each

| Topic             | Here                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pagination        | Cursor only, 50 by default and 200 at most, both published at `/v1/limits`. Deep pages cost what the first does.                                                                                                                                                                                                                                                                            |
| Rate limits       | One system. Every limit published. `RateLimit` on every response says what is left. `304` is free.                                                                                                                                                                                                                                                                                          |
| Errors            | `application/problem+json` with a stable `code`, a `hint`, `retryable` and the CLI exit code. One shape everywhere.                                                                                                                                                                                                                                                                         |
| Edits and retries | `If-Match` and `ETag`. `Idempotency-Key` on every write except secret-bearing responses. `expected_tree` to land only what was checked.                                                                                                                                                                                                                                                     |
| Mergeability      | `policy` and `checks` are on the change and always present. A state, not a `null`.                                                                                                                                                                                                                                                                                                          |
| Large diffs       | Planned to page per file and never fail whole. Not built.                                                                                                                                                                                                                                                                                                                                   |
| Webhooks          | [Built](/docs/api/webhooks): signed with Standard Webhooks, eight attempts over about 28 hours, replay of any range with one call, redelivery without a limit of twice.                                                                                                                                                                                                                     |
| Versions          | `v1` plus dated behaviour, and a build check that fails on any non-additive change.                                                                                                                                                                                                                                                                                                         |
| Credentials       | One token for REST and MCP, always expiring, created with an API call or [OAuth](/docs/api/oauth).                                                                                                                                                                                                                                                                                          |
| Waiting           | `wait` on any read, and the event stream, and `sync`.                                                                                                                                                                                                                                                                                                                                       |
| Speed             | Measured from one client, a single issue took about 300 ms on GitHub and GitLab, about 125 ms on git.cafe (117 ms of it the network), and 160–360 ms on Codeberg. Ours is a model until it is hosted: about 1 ms beyond the round trip for a cached read, 17–20 ms more for an uncached one. [The numbers and their assumptions](/docs/api/performance#against-other-forges-from-a-client). |
| Size              | A GitHub pull request is 22.7 KB and 50 of them 1.09 MB. Our change is 1.8 KB and 50 of them 60 KB, or 5 KB with `fields`.                                                                                                                                                                                                                                                                  |

## Where we are behind

This is a preview of an API on sample data. The others are in production.

- **They are real.** GitHub, GitLab, Bitbucket and git.cafe run in production with real data. Ours serves a sample.
- **Surface.** git.cafe publishes an OpenAPI document of about 2 MB, more than 50 webhook event types and, by its server card, 23 MCP tools. We have 192 operations and 24 event types.
- **Sign-in.** git.cafe also ships sign-in for agents without a registered client (its `auth.md`). We ship the authorization code flow, the device flow and dynamic registration, with real accounts behind the consent page, but only email and password to sign in with.
- **GraphQL.** GitHub and GitLab have it. We chose not to, and a client that needs it today has to use `fields`, `expand`, `batch` and `sync`.
- **Large diffs and runners.** Paging a large diff per file is not built, and the API hands pipeline jobs to runners but we do not run one yet. See the [roadmap](/docs/api/roadmap).
- **Years of ecosystem.** Libraries, answers, and people who already know them.

Things we could not read: Bitbucket's REST introduction page failed to load, so we have nothing confirmed about its pagination, error format, `fields` parameter or query language. We read only part of git.cafe's OpenAPI document and MCP server card. Tell us if something above is wrong and we will fix it.
